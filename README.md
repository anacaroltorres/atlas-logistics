# Atlas Logistics

## Sobre o projeto

O Atlas Logistics é um projeto de análise de dados desenvolvido em MySQL, com o objetivo de explorar informações de uma empresa fictícia do setor de logística.

O projeto analisa dados relacionados a clientes, motoristas, veículos e envios, permitindo avaliar aspectos operacionais e financeiros da empresa.

## Objetivos

- Estruturar um banco de dados relacional.
- Aplicar consultas SQL para extração e manipulação de dados.
- Verificar a integridade e a consistência das informações.
- Analisar indicadores operacionais e financeiros.
- Transformar dados em informações relevantes para a tomada de decisões.

## Tecnologias utilizadas

- MySQL

## Estrutura do projeto

- `01_Database`: arquivos de criação do banco de dados, criação das tabelas e inserção de registros.
- `02_SQL_Queries`: consultas SQL para validação dos dados e análises de negócio.
- `03_Documentation`: documentação da estrutura do banco de dados e dos resultados das análises.
